# Поставка

Здесь определены упаковка phplslow, проверки CI, платформы и выпуск версий.

## Упаковка

phplslow поставляется одним статическим бинарником без CGO. Контейнерного образа нет.

Причина: бинарнику ничего не нужно снаружи; образ при необходимости собирает клиент.

## CI и платформы

- CI — GitHub Actions: gofmt, vet, тесты и сборка с `CGO_ENABLED=0`.
- Сборки — `linux/amd64`, `linux/arm64`, `darwin/amd64` и `darwin/arm64`. Windows не поддерживается.

Причина: проверки и сборка без CGO выполняются в CI; набор платформ ограничен linux и darwin, поскольку демон
использует Unix-сокеты.

## Релиз и версия

Тег `vX.Y.Z` собирает бинарники с контрольными суммами и публикует их в GitHub Release. Версия зашита в бинарник
и печатается командой `phplslow --version`.

Причина: тег задаёт версию выпуска, контрольные суммы позволяют проверить бинарники, а команда показывает
версию установленного бинарника.

Реализация CI и выпуска релизов: DEV-14192.
