# Контракт сервера

phplslow отвечает по индексу Workspace и тексту файлов на диске. Здесь решены сигналы готовности, настройки,
расхождение открытого текста с диском, объединение типов и явная переиндексация.

## Готовность

- Ход индексации Workspace передаётся стандартным `$/progress` через `window/workDoneProgress/create`, если
  клиент объявил `window.workDoneProgress`. Иначе сигналов нет.
- Запросы ждут готовности индекса, как определено в [ADR 0001](0001-workspace-index-on-disk.md).

Причина: сигнал только показывает ход, а не разрешает отвечать по неполному индексу; стандартный механизм
не требует собственного протокола клиента.

## Настройки Workspace

- Файл настроек — `.phplslow.json` в корне Workspace. Сервер сам читает его и следит за изменениями;
  `workspace/configuration` не используется.
- `base` — путь к базовому дереву; `exclude` — glob-шаблоны исключённых файлов; `overrides` — файлы, чьи
  объявления побеждают другие объявления того же символа, внутри дерева или вне его.
- Относительные пути считаются от каталога файла настроек. Встроенные исключения phplslow объединяются
  с `exclude`, а не заменяются им.
- Правила обхода символических ссылок определены в [ADR 0001](0001-workspace-index-on-disk.md#файлы-workspace).

Причина: настройки не зависят от возможностей клиента; клиенту достаточно положить файл настроек.

## Явная база

База есть только при явно заданном `base` в `.phplslow.json`. Автоопределения нет. Без базы Workspace работает
сам по себе с собственным полным индексом, ни с кем не общим.

Причина: выбор общего базового дерева задаётся явно; отсутствие базы не мешает самостоятельной работе Workspace.

## Текст открытых документов

- Сервер отвечает по тексту на диске. `didOpen` и `didChange` с совпадающим текстом принимаются.
- Расхождение открытого текста с диском запоминается по файлу. Запрос с Position в нём и любой ответ,
  в котором есть место из него, получают `RequestFailed` с фактом `<путь>: open text differs from disk`.
  На сами уведомления `didOpen` и `didChange` ответ с ошибкой не отправляется.
- Отметка снимается после `didClose`, после совпадающего с диском `didChange` или когда диск совпал
  с открытым текстом.

Причина: иначе ответ молча содержит сдвинутые места; уведомление не допускает ответа с ошибкой.

## Объединение типов

Для `A|B` Reference идёт в члены обоих классов, где член есть; `definition` возвращает оба места. `?A` — то же,
что `A`. Для `mixed` и неизвестного типа Reference нет.

Причина: объединение сохраняет обе статически выведенные цели, а неизвестный тип цели не определяет.

## Переиндексация Workspace

`workspace/executeCommand` с командой `phplslow.reindex` принимает аргумент — URI Workspace. Команда
объявляется в `executeCommandProvider`. Ответ приходит, когда оверлей Workspace готов.

Причина: клиент явно запрашивает переиндексацию стандартным механизмом LSP и получает ответ по готовности оверлея.

Реализация: DEV-14182 — типы; DEV-14183 — свежесть и текст документов; DEV-14187 — Workspace поверх базы; DEV-14188 — исключения и Override; DEV-14189 — переиндексация Workspace.
