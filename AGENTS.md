# phplslow

PHP language server на Go: отвечает по LSP через stdio из индекса Workspace в SQLite на диске. Задачи — в YouTrack,
проект DEV (`https://yt.macrodigital.ru`).

## Правила

- phplslow is a standalone LSP server; it is designed against the LSP specification and its own contract, never
  against a particular client. Ни код, ни тесты, ни документы не называют конкретных клиентов и не подстраивают под
  них поведение.
- Работа идёт веткой `DEV-<N>` от `main` и пулл-реквестом в `main`; в `main` напрямую не пушат.
- Перед кодом — словарь [`CONTEXT.md`](CONTEXT.md) и решения в [`docs/adr/`](docs/adr/). Решение, которое меняет
  записанное, правит ADR в том же коммите.
- Репозиторий публичный: исходники, выгрузки, пути, имена и числа чужих закрытых проектов сюда не попадают. Ошибка,
  найденная на таком проекте, становится маленькой самописной фикстурой.
- Заимствованный код под MIT сохраняет уведомление авторов. Сторонние модули подключаются зависимостью в `go.mod`.
- Сборка без CGO: `CGO_ENABLED=0` в `Makefile` и CI. Поэтому `-race` не используется: ему нужен CGO.
- Go простой и скучный: интерфейс объявляет потребитель, нового понятия под гипотетический случай нет.
- Документы и комментарии описывают текущее состояние.
- Проверка — `make go`: gofmt, `go vet`, `go test`. CI — `.github/workflows/ci.yml`.

## Тесты

- Шов — процесс phplslow: `TestMain` собирает бинарник без CGO, тест запускает его, говорит с ним LSP по stdio и
  сверяет ответы. Внутренние таблицы SQLite тесты не читают.
- Каталог кэша пользователя у каждого теста свой (`XDG_CACHE_HOME`, `HOME`): индексы тестов не пересекаются и не
  трогают кэш пользователя.
- Фикстуры — маленькие самописные PHP в `testdata/`; место в файле тест находит по уникальной подстроке.
- Тест во внешнем пакете `_test`, на testify и таблицах; в теле теста нет логики. Ассерт — на значение.
- Строки phplslow в stderr — диагностика, а не протокол. Тест читает их только там, где другого наблюдаемого нет:
  было ли переиспользование индекса и какую причину phplslow записал, когда сессия кончилась отказом.
